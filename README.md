# Dog Fashion Studio (Beta)

Herramienta 3D para diseñar ropa para perros: maquetas de cristal de 36 razas ajustables a medidas reales, prendas con física de tela (XPBD), telas, patrones, texturas, logos y guía de diseño.

**Abrir la app:** https://ysbr27.github.io/dog-fashion-studio/

Funciona en el navegador (computadora y celular) sin instalar nada. Los proyectos se guardan en el navegador de cada persona.
